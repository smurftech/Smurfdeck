# Built-in CachyOS / KDE shortcuts

50 curated everyday presets. These are documented KDE defaults, not a measured popularity
ranking or an inspection of your personal key bindings. Apply a preset, then edit its chord
if your application differs. Meta is the Windows/Super key.

Use the action-library category filter or search by name/chord. Drag a preset to a key,
or select it and choose **Apply to key**. Each creates an independent editable keyboard
action. Application-specific shortcuts require that application to have focus.

Desktop Cut uses Ctrl+X. Konsole provides separate Copy/Paste shortcuts, but no standard
clipboard Cut action. Ctrl+C in a terminal usually interrupts a process; it is not Copy.

application settings. These presets assume a conventional Latin keyboard layout.
